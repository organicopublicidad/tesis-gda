## Estrategia de propuestas por universidad

Cada universidad recibe una propuesta adaptada a su **línea editorial e investigativa**, manteniendo intactos los constructos centrales (GDA, VCO, IPDET, antifragilidad) y los anclajes empíricos (Cauca, FEMNCAFE, PDET).

| Universidad | Énfasis adaptado | Marco teórico privilegiado |
|-------------|------------------|----------------------------|
| **UPM-TAPAS** | Economía agraria + sostenibilidad agroambiental + Sonia Benito | Merbah & Benito-Hernández (2023), Ostrom, Taleb |
| **Deusto-CETIS** | Competitividad territorial + innovación regional | Orkestra (Magro, Wilson), CGV, blockchain |
| **Loyola-DIS** | Desarrollo inclusivo + justicia social + ODS | Sostenibilidad, posconflicto, economía solidaria |
| **Mondragón** | Cooperativismo + economía social + gobernanza democrática | Ostrom, MCC, Fals Borda |
| **UAB** | Sociología económica + STS + territorios | CGV, sistemas sociotécnicos |
| **UPV** | Ingeniería agroalimentaria + cadenas digitales | Blockchain, trazabilidad, EUDR |

## Reglas de organización

1. Cada carpeta universitaria contiene: README + propuesta + carta de motivación + documentos adicionales.
2. Si llega respuesta de cualquier universidad → actualizar README + bitácora maestra.
3. Si una universidad se concreta → marcarla como "Concretada" y actualizar prioridades.
4. Documentos en formato `.docx` viven en GitHub (versionados); PDFs solo en disco local.
